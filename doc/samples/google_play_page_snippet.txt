The Google Play app page is a large HTML document. The only part this package reads is the entry below
(mock values, same structure as a real page). The version is the first element, and it is accepted only when it is
directly followed by the minimum-Android-SDK block `[[[36]],...`:

  ..."141":[[["1.3.0"]],[[[36]],[[[29,"10"]]]]],"145":[null,[null,"Bug fixes and performance improvements."]],
  "146":[["Jan 1, 2026",[1767225600,0]]]...

  [[["1.3.0"]],[[[36]],...        <- matched by PlayStoreParser: version = 1.3.0
   ^^^^^^^^^^^^   ^^^^^^^^^
   version        minimum Android SDK, required right after the version

Mock pages used by the unit tests live in test/fixtures/.
